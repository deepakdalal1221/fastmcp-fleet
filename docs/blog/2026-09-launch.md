# fastmcp-fleet: 86 mock MCP servers, offline-first, one command

> *A local FastMCP platform for agent development, testing, and demos — without touching a single live API.*

## The problem

Building an AI agent that uses tools well is hard. Testing it is harder. If you want to see whether your agent can:

- Open a Jira issue from a Sentry alert
- Post a Slack thread linking a GitHub PR to a Notion doc
- Refund a Stripe charge after a customer complaint
- Query PagerDuty for the last 5 incidents and summarize them

...you either need real API keys for all those services (expensive, credential-heavy, non-deterministic) OR you write mocks yourself (tedious, per-server, brittle).

**fastmcp-fleet solves this** by shipping a fleet of MCP-protocol mocks that look and behave enough like the real APIs to let agents rehearse full multi-step workflows — no accounts, no credentials, no network.

## What's inside

- **86 mock MCP servers** across GitHub, Jira, Slack, Notion, Stripe, Cloudflare, Datadog, Airtable, Trello, HubSpot, Freshdesk, and 75 others
- **10 servers with full CRUD** persisted through a per-server SQLite Local Store — `create_issue` → `list_issues` really returns the created issue, across process restarts
- **Two runtime modes**:
  - `make dev` — single Python process, all 86 servers mounted at `http://localhost:9000/mcp` in ~2 seconds
  - `make up` — full docker-compose stack, each server in its own container, orchestrated sequentially
- **335+ tests**: contract, trajectory, fixture-schema, CRUD chain
- **Fully offline**: an `OfflineTransport` intercepts every HTTP call and serves fixture JSON; a `MCP_SEED` env var seeds deterministic randomness where needed

## Try it in 60 seconds

```bash
git clone https://github.com/deepakdalal1221/fastmcp-fleet
cd fastmcp-fleet
uv sync --extra all --extra dev
make dev            # 86 servers, 315+ tools at :9000
```

Then wire Claude Desktop or MCP Inspector at `http://localhost:9000/mcp` and start calling tools.

Or run the built-in scripted demo:

```bash
make demo           # scripted github → jira → slack cross-server trajectory
```

## Why it matters

Every serious agent framework will need this eventually — offline, deterministic, credential-free tool simulation. **The alternatives today** are either full production accounts (expensive, credential leaks, rate limits) or hand-rolled per-project mocks (tedious, incomplete, hard to share). fastmcp-fleet is neither. It's:

- **Open source (MIT)** — clone it, extend it, contribute a server via `uv run mcp-create <id>`
- **Extensible in seconds** — add a server, its tools.py is a template, fixtures are JSON, state is SQLite
- **Testable at scale** — 335 pytest tests, CI on GitHub Actions, CodeQL security scans, drift-detection contract test enforces manifest ↔ impl sync
